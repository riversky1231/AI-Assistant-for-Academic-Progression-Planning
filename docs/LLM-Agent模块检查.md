# LLM 与 Agent 模块检查

检查日期：2026-09-18。

## 结论

在当前约定的“非流式升学咨询 + 本地数据工具 + Redis 多轮会话 + 固定张雪峰视角”范围内，核心链路已闭合，可以提交。尚未以真实模型和生产环境完成端到端质量验收，不将自动化协议测试视为模型建议质量保证。

## 本次补充与修复

- 将“读取锁所有者 → 写入会话”的两步操作改为 Redis Lua 原子操作，阻止已过期工作线程覆盖新历史。
- 补充锁归属变更、Redis 保存失败、模型超时、畸形/截断输出、推荐正常调用、供应商续轮字段保留、工具次数上限及重复调用 ID 的测试。
- 核对已有的 `conversationId` 输入兼容与 Skill 诊断信息，保留 `conversation_id` 为推荐字段。

验证命令：`cd backend` 后运行 `mvn -B package`。本次结果为 **41 项测试，0 失败、0 错误、0 跳过**；本机 Redis 可用，Redis 读写与原子保存测试实际执行。LLM 使用本地模拟 HTTP 服务，不发送请求到真实付费模型。数据库、生产部署与真实模型回答质量未在本次验收。

## 已明确的边界

- 不支持流式输出、联网搜索、模型切换、任务状态查询或取消接口。
- 没有整条咨询的硬截止时间、幂等键、自动重试、token 费用统计；客户端需处理多轮等待和重复发送。
- 背景研究不等于最新招生、就业数据；当前业务库仍是演示历史数据。
- Skill 的咨询步骤由提示词指导，没有服务端状态机强制每个步骤，也不以 `instructions_injected` 证明模型遵从。
- 会话仅保留有限轮次，裁剪或过期后可能需要用户补充信息；工具明细不会跨轮持久化。
- Redis 网关面向当前单端点部署，未实现 Redis Cluster 重定向或跨槽脚本支持。

对外字段、错误码和可复制请求见 [Agent 接口文档](Agent接口文档.md)。
