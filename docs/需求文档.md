# B 组后端需求文档

## 1. 项目范围

本模块负责升学规划系统的后端数据查询、规则推荐、数据持久化、缓存、权限验证及 Agent/LLM 问答。不负责微信小程序页面、跨组联调。

## 2. 功能需求

1. 用户可以注册、登录、退出、查询当前权限、维护账号资料、修改密码、找回密码，并可使用微信登录创建或进入账号。
2. 已授权用户可以按关键词、省份查询学校列表。
3. 已授权用户可以查询学校、专业和招生记录详情。
4. 已授权用户可以提交省份、科类、分数、位次、专业偏好和地区偏好，得到“冲/稳/保”推荐。
5. 推荐必须使用历史最低位次与用户位次之差分类，分数不参与分类。
6. 系统使用 MySQL 保存学校、专业、招生和权限数据。
7. 系统使用 Redis 缓存学校详情和推荐结果。
8. Swagger 必须可以查看接口契约。
9. 管理员可以查询账号列表、创建账号、启停账号和重置账号密码。

## 3. 非功能需求

- 使用 DTO 做输入白名单和 Jakarta Validation 参数校验。
- MyBatis 查询必须使用参数绑定，禁止拼接用户输入。
- 密码必须以 PBKDF2 哈希存储，响应中不得返回密码字段。
- 用户响应只能返回安全资料，不得返回密码哈希、找回凭证或内部密钥。
- 未登录返回 401，无权限返回 403，不存在的学校返回 404。
- 同一用户名 5 分钟内最多尝试登录 10 次，超过后返回 429。
- 找回密码必须校验绑定手机号或邮箱，并进行限流。
- 数据库约束必须阻止招生记录引用其他学校的专业。
- Redis 缓存异常时，学校和推荐查询降级访问 MySQL。

## 4. 验收条件

- 至少包含 10 所学校；演示数据为 18 所学校、54 个专业、54 条招生记录。
- 福建物理类、580 分、15000 位、计算机条件能返回冲稳保结果。
- 非法分数、位次、科类和过长文本会被拒绝。
- 未携带有效 Redis Token 不能访问学校与推荐接口。
- Maven 自动化测试通过。
