# 向远 · 微信小程序

原生微信小程序（JavaScript / WXML / WXSS），无需 npm 安装或构建。接口以当前 `backend/src/main` 的 Spring Boot 实现为准。

当前 `project.config.json` 中的 AppID 为 `wx8ab1f880d51cff5f`。

## 导入运行

1. 在微信开发者工具中导入**仓库根目录**，`project.config.json` 已指定 `miniprogram/` 为小程序目录。
2. 当前项目 AppID 为 `wx8ab1f880d51cff5f`。如果使用自己的小程序，需要把 `project.config.json` 中的 `appid` 换成自己的 AppID。
3. 启动现有 MySQL、Redis 和 Java 后端，默认服务地址为 `http://127.0.0.1:8080`。后端启动方式和依赖见仓库 README 顶部说明。
4. 开发者工具连接本机 HTTP 服务时，在“详情 → 本地设置”中临时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。项目默认保留域名校验，不替你关闭发布检查。
5. 使用后端分配的账号登录，或在登录页注册新账号。未修改的 SQL 种子账号为 `admin` / `Admin@123`（由后端 `PasswordHasherTest` 验证）；页面不会预填或保存密码。已修改数据库密码时以实际配置为准。
6. 体验版、正式版前，在 `config/api.js` 的 `trial`、`release` 填写自己的 HTTPS 后端地址，并在微信公众平台配置 request 合法域名。留空时明确提示未配置，不会请求本机。真机上的 `127.0.0.1` 不是开发电脑。

## 真机连接排查

手机浏览器能访问 `/health`，只说明浏览器到后端可达，还需在小程序内点击“我的 → 服务连接”，验证微信的 `wx.request` 是否也能访问。

- 从仓库根目录打开项目，核对 `config/api.js` 的 `develop` 地址是电脑当前的局域网 IPv4 地址，手机与电脑处于可互通的网络。
- 开发者工具中的代理设置和“详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”是不同设置；检查当前项目的实际设置。
- 结束旧真机调试，重新编译并扫码。连接失败时，在真机调试的 Console 中搜索 `[request:fail]`，展开查看 `url`、`errMsg`、`errno` 和 `errCode`。日志仅在开发版输出，不包含请求头、登录 token 或请求数据。
- `url not in domain list` 表示微信域名校验失败；`timeout` 表示请求超时；其他网络错误应根据原始错误继续定位。`Provisional headers are shown`、组件预加载警告和“工具未校验合法域名”提示本身不能确定失败原因。
- 如果当前使用灰度基础库，可在开发者工具中选择可用的稳定基础库并重新调试，以比较是否仅在灰度版本复现。
- HTTP 401 / 403 / 503 与网络失败分别处理：检查登录状态、账号权限或后端服务。直接在浏览器中访问 `/schools` 不带登录凭证时返回 401 是正常情况。

## 页面与数据

| 页面 | 功能 | 数据来源 |
|---|---|---|
| 首页 | 规划入口、考生档案摘要、院校概览 | `GET /schools?limit=3`、本地档案 |
| 院校库 | 关键词和学校所在地筛选，最多 50 条 | `GET /schools` |
| 院校详情 | 专业、历史最低分/位次，按生源地/科类/年份筛选 | `GET /schools/{id}` |
| 志愿推荐 | 生源省份、科类、分数、位次、专业和地区偏好 | `POST /recommend` |
| 推荐结果 | 冲/稳/保分组、历史数据、原始推荐理由 | 后端本次响应 |
| 智能咨询 | 多轮追问、档案草稿、回答复制、会话恢复 | `POST /agent/chat` |
| 咨询依据 | 院校查询、历史录取、冲稳保结果和背景资料原文 | 本轮响应的 `sources` |
| 我的 | 本机档案、账号资料、改密码、账号权限、账号管理、服务连接、退出 | `/auth/me`、`/auth/profile`、`/auth/change-password`、`/auth/users`、`/health`、`/auth/logout` |
| 登录 | 账号密码登录、注册、找回密码、微信登录，成功后返回原页面 | `/auth/login`、`/auth/register`、`/auth/forgot-password`、`/auth/wechat-login` |

统一请求层解析 `{ code, message, data }`，动态使用登录响应的 `token_name` / `token_value` 设置请求头。401 清理本机账号数据并跳转登录，403 显示权限不足，429 提示稍后重试；网络失败可重试。不同查询的响应不会覆盖更新的筛选结果。

档案与最近推荐只保存在微信本地存储，没有新增后端接口。退出、切换账号、登录失效均清除这些数据。后台请求携带必要的考生信息；前端不缓存密码、不包含服务端密钥。最近推荐是已生成的快照，修改档案后须重新查询才会更新。

当前 Java 后端支持账号密码登录、注册、找回密码、微信登录、账号资料维护、管理员账号管理及 `/agent/chat` 多轮咨询，小程序已接入以上能力。收藏和云端档案尚未实现。Agent 接口见 [接口文档](../docs/Agent接口文档.md)。

## 智能咨询

从首页“选择有疑问？一起聊聊”、我的“我的智能咨询”或推荐结果页进入。咨询页延续米白、深绿的设计，提供问题引导、对话气泡、底部输入区和独立的依据详情页。引用考生档案只填入可编辑的草稿，点击发送后才会传给后端；从结果页进入时使用该次推荐的档案快照，已有草稿不会被覆盖。

后端需开启并配置 LLM，账号需有 `recommend:use`，院校工具还需 `school:read`。咨询接口单独使用 300 秒请求超时，以覆盖多轮模型调用；其他接口仍为 15 秒。等待期间禁止重复发送，不自动重试；返回页面时会继续显示仍在处理的咨询。403、409、429、502、503、504 和网络失败均提供提示，保留未成功的问题。服务端明确返回会话过期时，需要点击“开启新咨询”，重新补充背景。

对话和草稿仅保存在本次小程序运行的内存中，保留最近 8 轮完整问答；开启新咨询、退出、切换账号、登录失效或重启小程序后清除。服务端仍按自身规则在 Redis 中保存会话并在成功回复后续期 30 分钟，前端清空不等于立即删除服务器会话。小程序没有云端会话列表或恢复历史会话的接口。

回答使用原生 `text` 渲染标题、列表、粗体和代码等基础格式，HTML 和链接只作为文字展示。依据详情直接保留工具返回的分组、排序、理由和免责声明；背景研究独立标为“背景参考”，原文可展开。界面不展示模型指令路径或哈希。

## 推荐展示规则

直接保留后端分组与排序，不在前端重新算概率。后端以 `历史最低位次 - 考生位次` 分组：小于 -2000 为冲，-2000 至 2000 为稳，大于 2000 为保；分数不参与分类。每类最多 5 个专业记录，同一学校可能出现多个专业。当前 SQL 演示数据覆盖福建物理类，其他条件返回空结果是正常情况。

## 检查与验收

在仓库根目录运行：

```powershell
node --test tests/miniprogram.test.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File tests/check_miniprogram_markup.ps1
```

Node 测试通过模拟 `wx` 验证真实接口契约、鉴权、异常、请求竞态、表单边界、页面数据流与页面注册；不访问真实后端，不代表微信运行时渲染验收。

开发者工具手工验收：

1. 未登录浏览首页；进入院校库点击登录，登录后应回到院校库。
2. 搜索“福州”，切换福建/浙江；空关键词不发送空字符串查询参数。
3. 从列表进入院校详情，切换生源地/科类/年份。
4. 提交福建、物理类、580 分、15000 位、计算机，查看三组推荐和详情跳转；地区可填写“江浙沪”。
5. 测试空分数、0 分、750 分、超范围分数、空位次、0 位次；非法值不发请求。
6. 查询未覆盖省份或历史类，显示无数据，不显示虚构推荐。
7. 让 Token 失效后再次查询，应跳转登录；更换账号不会显示之前的档案。
8. 关闭服务后重试，检查网络错误、加载结束和恢复。
9. 我的页面检查资料保存、改密码、权限、服务连接、退出；管理员账号应能展开账号管理并执行启停或重置密码。
10. 真机验证长院校名、键盘收起、底部安全区域和四个导航入口。
11. 从首页进入智能咨询，登录后回到咨询页；填写问题，验证等待状态、连续追问、复制回答和新咨询。未配置模型时应显示服务不可用。
12. 使用考生档案填入草稿，确认可编辑且未自动发送；从推荐结果进入时确认使用该次档案快照。
13. 查看本轮依据，验证院校跳转、冲稳保原始分组、空数据和背景原文展开。
14. 会话过期后确认问题保留、新咨询不携带旧 ID；请求处理中返回再进入，回复应正常呈现；切换账号后旧回复不能出现。
15. 在 iOS / Android 真机检查咨询键盘弹起、收起、长回答滚动与底部安全区。
