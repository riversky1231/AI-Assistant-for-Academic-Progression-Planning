# 向远 · 微信小程序

原生微信小程序（JavaScript / WXML / WXSS），无需 npm 安装或构建。接口以当前 `backend/src/main` 的 Spring Boot 实现为准。

## 导入运行

1. 在微信开发者工具中导入**仓库根目录**，`project.config.json` 已指定 `miniprogram/` 为小程序目录。
2. 将项目的 `appid` 换成自己的小程序 AppID。当前 `touristappid` 仅用于游客模式查看，真机预览需要有效 AppID。
3. 启动现有 MySQL、Redis 和 Java 后端，默认服务地址为 `http://127.0.0.1:8080`。后端启动方式和依赖见仓库 README 顶部说明。
4. 开发者工具连接本机 HTTP 服务时，在“详情 → 本地设置”中临时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。项目默认保留域名校验，不替你关闭发布检查。
5. 使用后端分配的账号登录。未修改的 SQL 种子账号为 `admin` / `Admin@123`（由后端 `PasswordHasherTest` 验证）；页面不会预填或保存密码。已修改数据库密码时以实际配置为准。
6. 体验版、正式版前，在 `config/api.js` 的 `trial`、`release` 填写自己的 HTTPS 后端地址，并在微信公众平台配置 request 合法域名。留空时明确提示未配置，不会请求本机。真机上的 `127.0.0.1` 不是开发电脑。

## 页面与数据

| 页面 | 功能 | 数据来源 |
|---|---|---|
| 首页 | 规划入口、考生档案摘要、院校概览 | `GET /schools?limit=3`、本地档案 |
| 院校库 | 关键词和学校所在地筛选，最多 50 条 | `GET /schools` |
| 院校详情 | 专业、历史最低分/位次，按生源地/科类/年份筛选 | `GET /schools/{id}` |
| 志愿推荐 | 生源省份、科类、分数、位次、专业和地区偏好 | `POST /recommend` |
| 推荐结果 | 冲/稳/保分组、历史数据、原始推荐理由 | 后端本次响应 |
| 我的 | 本机档案、最近推荐、账号权限、服务连接、退出 | `/auth/me`、`/health`、`/auth/logout` |
| 登录 | 账号密码登录，成功后返回原页面 | `POST /auth/login` |

统一请求层解析 `{ code, message, data }`，动态使用登录响应的 `token_name` / `token_value` 设置请求头。401 清理本机账号数据并跳转登录，403 显示权限不足，429 提示稍后重试；网络失败可重试。不同查询的响应不会覆盖更新的筛选结果。

档案与最近推荐只保存在微信本地存储，没有新增后端接口。退出、切换账号、登录失效均清除这些数据。后台请求携带必要的考生信息；前端不缓存密码、不包含服务端密钥。最近推荐是已生成的快照，修改档案后须重新查询才会更新。

当前 Java 后端支持账号密码登录及 `/agent/chat` 多轮咨询；小程序暂未添加对话页面。微信一键登录、注册、收藏和云端档案尚未实现。Agent 接口见 [接口文档](../docs/Agent接口文档.md)。

## 推荐展示规则

直接保留后端分组与排序，不在前端重新算概率。后端以 `历史最低位次 - 考生位次` 分组：小于 -2000 为冲，-2000 至 2000 为稳，大于 2000 为保；分数不参与分类。每类最多 5 个专业记录，同一学校可能出现多个专业。当前 SQL 演示数据覆盖福建物理类，其他条件返回空结果是正常情况。

## 检查与验收

在仓库根目录运行：

```powershell
node --test tests/miniprogram.test.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File tests/check_miniprogram_markup.ps1
```

Node 测试通过模拟 `wx` 验证真实接口契约、鉴权、异常、请求竞态、表单边界、页面数据流与页面注册；不访问真实后端，不代表微信运行时渲染验收。

开发者工具手工验收：

1. 未登录浏览首页；进入院校库点击登录，登录后应回到院校库。
2. 搜索“福州”，切换福建/浙江；空关键词不发送空字符串查询参数。
3. 从列表进入院校详情，切换生源地/科类/年份。
4. 提交福建、物理类、580 分、15000 位、计算机，查看三组推荐和详情跳转；地区可填写“江浙沪”。
5. 测试空分数、0 分、750 分、超范围分数、空位次、0 位次；非法值不发请求。
6. 查询未覆盖省份或历史类，显示无数据，不显示虚构推荐。
7. 让 Token 失效后再次查询，应跳转登录；更换账号不会显示之前的档案。
8. 关闭服务后重试，检查网络错误、加载结束和恢复。
9. 我的页面检查权限、服务连接、退出；重新登录后本机档案为空。
10. 真机验证长院校名、键盘收起、底部安全区域和四个导航入口。
